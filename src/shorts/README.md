## 검수 참고

- 원본 파일 자체가 점프컷 편집본이라 문장 중간이 잘린 곳이 있습니다. 마무리 발언의 "혁신은 대부분 **구미**에서 왔다. 다음은 **우리**에게서"는 이 파일에서 "혁신은 대부분 **우리**에게서 왔다"로 이어 붙어 있어(1123.8s·1126.4s 컷) 뜻이 반대가 되므로 쓰지 않았습니다.
- Q&A 중 "스탠퍼드 졸업생 280여 명 중 취업자 20명 미만" 일화는 출처를 확인할 수 없어 컷에서 뺐습니다.
- 1번의 "매년 똑같은 강의는 단순 반복이라 대체될 수 있다"는 원본 1680.3s 컷 앞뒤("简单的 | 把那个替掉")를 포럼 전체 자막 기준으로 이어 번역했습니다.
- 웅극중 편집본은 허첸 편집본보다 훨씬 촘촘하게 잘려 있어 숫자가 빠진 문장이 있습니다.
  - 5번 "공립 중학교 교사 연간 340교시"는 음성에서 숫자가 잘렸지만 같은 구간 슬라이드(와이드 샷)에 「10×34=340 차시」가 크게 나와 그 숫자로 자막을 달았습니다. 헤드 카피 "2.5배"는 슬라이드의 855÷340으로 계산한 값입니다.
  - 6번의 "영어 비율 90% 이상, 데이터가 80%면 불합격"은 음성과 화면 모두에서 숫자가 빠져 "기준에 못 미치면 불합격"으로만 옮겼습니다.
  - 4번 "중간관리자를 정리해 관리직 급여를 하나도 두지 않았다"는 편집으로 "全部砍了"가 빠진 문장을 포럼 전체 자막 기준으로 이어 옮겼습니다.
- 6번에 나오는 ClassIn AI 강의 분석은 중국 기관의 사례입니다. AI 강의 평가는 Notion 기준 현재 중국어 수업·실시간 수업에만 제공되므로, 게시 문구에서 한국어 수업 지원을 약속하지 않도록 합니다.

## 다시 만들기

```bash
npm run shorts:cut -- "<경로>/4. 허첸 진행자.mp4"     # source가 같은 스펙만 골라 public/shorts/<id>.mp4 생성
npm run shorts:cut -- "<경로>/5. 웅극중 진행자.mp4"
npm run shorts:render                    # out/shorts/<id>.mp4
```

구간·자막·카피는 `src/shorts/specs/<id>.json` 하나에서 고칩니다. 시간은 모두 원본 파일 기준 초이고, 클립 위치로의 변환은 `src/shorts/timeline.ts`가 합니다. 구간을 바꾸면 `shorts:cut`부터 다시 돌립니다.

## 구조

```
src/shorts/ShortForm.tsx      # 숏폼 레이아웃 — 헤드 카피 · 크롭 영상 · 왼쪽 위 이름표 · 영상에 겹친 원어/한국어 자막 · Classin
src/shorts/specs/*.json       # 숏폼별 구간 · 자막 · 카피 · 크롭(원본 기준 초)
src/shorts/timeline.ts        # 원본 시각 → 클립 시각 변환, 프레임 고정 구간 길이
scripts/cut-clips.py          # 스펙대로 원본을 잘라 이어 붙여 public/shorts/<id>.mp4 생성
```

중국어 자막 서체(Noto Sans SC 서브셋, `public/fonts/NotoSansSC-*.woff2`)는 `src/shared/fonts.ts`에서 함께 불러옵니다.
