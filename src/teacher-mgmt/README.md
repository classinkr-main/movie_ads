## A 라이트 편 (22초 · `TeacherMgmt`)

**"AI로 강의 평가, 데이터로 강사 관리."** — 원장이 모든 수업을 참관할 수 없다는 문제에서 출발해, AI가 모든 수업을 같은 기준으로 평가하고
그 결과로 강사별 추이·면담 준비 노트까지 이어지는 흐름을 4씬으로 보여줍니다. "너무 빠르지 않게"라는 요청에 맞춰 씬당 1–2개 비트만 두고,
글자 스태거 2.2–2.4f, 레이아웃 스프링은 무오버슈트(`SMOOTH`), 각 씬 끝에 1–2.5초의 정지 호흡을 뒀습니다.

## B 가치 편 (26초 · `TeacherMgmtValue`)

**"원장님은 편하게, 강사는 객관적으로."** — A편과 같은 주제를 **가치 중심**으로 다시 쓴 두 번째 편입니다. 디자인 테마는 A편·쇼릴과 같은
화이트·아이보리 + 연두이고, 문제 제기 대신 "매 수업 옆에 코치를"이라는 약속에서 출발해 자동 피드백 루프("수업의 퀄리티가 복리로 쌓입니다") → 연두 포인트 → 원장님이 얻는 것 →
강사가 얻는 것 → 두 사람이 같은 데이터로 대화한다는 흐름으로 A편보다 4초 깁니다. 타이틀은 모든 씬에서 **2줄 고정**(각 줄 `nowrap`)이고, 좌측 상단 거대 아웃라인 번호(01–03)는 2/3쯤 보이도록 내려 두었습니다(`TmvLayout`의 `top: -135`).

### 카피 근거와 검수 참고
