# 아이디어 폴더

Classin 영상 콘텐츠 후보를 한곳에 모아두는 폴더입니다. 현재 제작된 영상(30초 AI 쇼릴)은 저장소 루트 [README](../README.md)를 참고하세요.
아이디어는 **기획 메모**이며, 확정되면 별도 Remotion 컴포지션(또는 촬영/생성 작업)으로 넘깁니다.

## 공통 가이드

- **브랜드 톤**: 화이트·아이보리 베이스 + 연두 포인트 + Classin Green `#084734`. 팔레트는 `src/lib/theme.ts`, 폰트는 Pretendard.
  `#084734`는 칠판 초록과 같은 계열이라 01번의 칠판 연출과 자연스럽게 이어집니다.
- **예시 수업 연속성**: 중2 국어 A반 · 3단원 비유와 상징 · 윤동주 「서시」 · 이서윤 선생님(가상). 인물·수치는 모두 연출용입니다.
- **콘셉트 목업 고지**: 기능 화면은 실제 UI가 아니라 콘셉트 목업이므로, 게시 전 실제 지원 범위(언어·모델·채점 범위 등)를 맞춥니다.
- **AI 강의 평가**는 Notion 기준 현재 중국어 수업·실시간 수업에만 제공됩니다. 언어를 단정하는 표현은 쓰지 않습니다.
- **검수 표시**: 외부 사실(연도·용어 출처·트렌드)은 문서에 `⚠ 확인 필요`로 표시했습니다. 제작 전에 출처를 확인하고 표시를 지웁니다.
- **CTA**: `classin.co.kr/contact`

## 새 아이디어 추가하기

1. `NN-짧은-영문-이름.md` 파일을 만듭니다. (예: `04-teacher-interview.md`)
2. 아래 항목 순서를 따르면 다른 문서와 비교하기 쉽습니다.
   **한 줄 요약 → 목적 · 타깃 → 핵심 장치 → 구성안(비트표) → Classin 연결 → 제작 방식 → 열린 질문**
3. 위 목록 표에 한 줄을 추가합니다.
