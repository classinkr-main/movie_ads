# 02 · 플립러닝 · 에듀테크 트렌드 설명

> **한 줄 요약** — 플립러닝이 무엇인지, 지금 에듀테크가 어디로 가는지를 쉽게 설명하고, 마지막에 "Classin으로 하면 이렇게"로 연결하는 정보형 영상 시리즈.

**상태** 💡 아이디어 · **형식** 설명 영상(explainer) · **길이** 시리즈 4편 × 60–90s · **톤** 차분하고 신뢰감 있는 정보 전달 (정보 7 : 브랜드 3)

## 목적 · 타깃

- **목적**: 광고가 아닌 "교육 콘텐츠"로 접근해 Classin을 에듀테크 흐름을 아는 브랜드로 인식시키기
- **타깃 후보**: 학원 원장 · 교사 · 교육기관 담당자 (학부모는 2차)
- **채널 후보**: 유튜브, 링크드인, 블로그 임베드, 영업 자료 첨부

## 시리즈 구성

| 편 | 제목(가안) | 핵심 메시지 | 길이 |
| --- | --- | --- | --- |
| EP1 | 플립러닝, 1분 만에 이해하기 | 강의는 집에서, 수업은 교실에서. 수업 시간의 쓰임이 바뀐다 | 60–75s |
| EP2 | 왜 지금 플립러닝인가 | 영상·AI·원격 수업 도구가 갖춰지면서 실제로 해볼 수 있는 환경이 됨 | 60–90s |
| EP3 | 에듀테크 트렌드 5가지 | 지금 교육 현장에서 주목받는 흐름을 한 장씩 정리 | 75–90s |
| EP4 | Classin으로 플립 수업 만들기 | 사전 학습 → 수업 → 사후 확인을 Classin AI 기능에 대응시켜 시연 | 75–90s |

## EP1 구성안 · 플립러닝, 1분 만에 이해하기

| 시간 | 내용 | 화면 |
| --- | --- | --- |
| 0–5s | 질문 훅: "수업 시간에 강의만 하고 계신가요?" | 큰 타이포 + 칠판 텍스처 |
| 5–20s | **전통 수업**: 교실에서 강의 → 집에서 숙제 | 두 칸 타임라인 (교실 / 집) |
| 20–40s | **플립러닝**: 개념은 사전 영상으로 → 교실에서는 토론·문제풀이·피드백 | 두 칸이 좌우로 뒤집히는 모션 (flip) |
| 40–55s | 장점: 학생별 속도에 맞춰 학습 / 교사가 수업 중 개별 피드백 가능 | 아이콘 3개 순차 등장 |
| 55–70s | 주의할 점: 사전 학습을 안 해오면? → 확인 퀴즈와 피드백이 필요 | 체크 퀴즈 카드 |
| 70–75s | 다음 편 예고 + 로고 | 연두 전환 띠 |

> 핵심 비주얼은 **"뒤집힌다(flip)"**. 교실과 집의 역할이 뒤바뀌는 장면을 2D 카드 플립으로 표현하면 설명 없이도 개념이 전달됩니다.

## 다룰 내용 후보

### 플립러닝 개념 (EP1 · EP2)

- 정의: 개념 학습(강의)은 수업 전 영상으로, 수업 시간은 토론·문제 풀이·피드백 중심으로 운영하는 방식
- 용어 유래: 미국 교사 Jonathan Bergmann · Aaron Sams가 2000년대 후반 수업 영상을 배포하며 알려졌고, 『Flip Your Classroom』(2012)으로 확산 ⚠ 확인 필요
- 성공 요소 4가지 (F-L-I-P: Flexible Environment · Learning Culture · Intentional Content · Professional Educator) — Flipped Learning Network 제시 ⚠ 확인 필요
- 흔한 실패 원인: 사전 영상이 너무 길다 / 학생이 안 보고 온다 / 수업 시간 활동이 설계되지 않았다

## Classin 연결 가설 (EP4)

플립러닝의 세 단계에 AI 기능을 대응시키는 구조입니다.

| 단계 | 하는 일 | 대응 가능한 Classin 기능 |
| --- | --- | --- |
| 수업 전 | 사전 학습 자료 만들기 | 02 AI 스크립트 · 강의 요약 (지난 수업 요약을 복습 자료로) |
| 수업 중 | 토론·문제 풀이·피드백 | 실시간 수업 + 04 실시간 자막 (다국어 학생 참여) |
| 수업 후 | 이해 확인 · 질문 응대 | 03 숙제 출제 · 채점, 05 AI 에이전트 |

> 위 연결은 **기획 가설**입니다. 기능이 사전 학습 용도로 실제 어떻게 쓰이는지는 제품팀과 확인한 뒤에 EP4를 확정합니다.
