# 03 · Classin 기능 소개 시리즈

> **한 줄 요약** — Classin 기능을 **한 편에 하나씩** 소개하는 짧은 시리즈. 기존 30초 쇼릴의 5개 AI 기능을 각각 독립된 영상으로 확장한다.

**상태** 💡 아이디어 · **형식** 기능 소개 · **길이** 편당 20–30s · **톤** 명확하고 구체적 (문제 → 해결 → 결과)

## 목적

- 쇼릴(총론)을 본 사람에게 **각론**을 제공: "그래서 그 기능은 정확히 뭘 해주는데?"
- 영업 · 상담 자리에서 **기능별로 골라 보낼 수 있는** 자료
- 신규 기능이 생기면 **같은 포맷으로 한 편만 추가**하면 되는 확장 가능한 구조

## 에피소드 목록

| EP | 기능 | 훅(문제 상황) | 보여줄 핵심 | 결과 한 줄(예시 수치) | 재사용 소스 |
| --- | --- | --- | --- | --- | --- |
| 01 | AI 강의 평가 | "내 수업, 객관적으로 어땠을까?" | 45분 파형 스캔 → 발문 14회 · 구간별 분석 → 종합 점수와 4개 영역 → 강점/개선 포인트 | 종합 88점, 수업 후 바로 리포트 | `F01Eval` |
| 02 | AI 스크립트 · 강의 요약 | "수업 내용을 다시 정리하려면 한 시간…" | 화자 구분 스크립트 → 핵심 문장 하이라이트 → 요약 패널(핵심 개념 · 과제) | 수업이 끝나면 요약이 완성 | `F02Script` |
| 03 | AI 숙제 출제 · 채점 | "출제도 채점도 밤 12시에…" | 출제 조건 입력 → 5문항 생성 → 학생 답안 채점 · 서술형 피드백 | 제출 24/28, 반 평균 82 | `F03Homework` |
| 04 | AI 자동 번역 · 실시간 자막 | "다국어 학생이 수업을 따라올 수 있을까?" | 교사 발화 → English · 中文 · 日本語 · Tiếng Việt 자막 순환 → 해당 학생 타일 | 한 번 말하면 4개 언어로 | `F04Subtitle` |
| 05 | AI 에이전트 | "밤에 온 학생 질문, 학부모 상담 준비…" | 비서 설정 → 학생 질문에 수업 근거 답변 → 교사용 상담 초안 | 성취도 72→78→90, 제출률 92% | `F05Agent` |
| 06+ | (추가 기능) | — | — | — | 마케팅 · 제품팀 목록 확인 후 추가 |

> 수치와 화면은 모두 기존 쇼릴과 동일한 **예시 수업(중2 국어 A반)** 기준 연출용입니다.
> AI 강의 평가(EP01)는 현재 중국어 수업 · 실시간 수업에만 제공되므로 영상에서 언어를 단정하지 않습니다.
> AI 외 기능(수업 환경, 화이트보드 등)은 이 저장소에 근거 자료가 없어 **마케팅 · 제품팀의 기능 목록을 받은 뒤** 06번부터 추가합니다. ⚠ 확인 필요

## 편당 포맷 (고정 템플릿)

모든 편이 같은 틀을 따라야 시리즈로 보입니다. 길이는 25초 기준입니다.

| 시간 | 구간 | 내용 |
| --- | --- | --- |
| 0–1.5s | 시리즈 스팅 | "Classin AI · 01/05" 챕터 번호 + 로고 마크 |
| 1.5–5s | 훅 | 교사의 고민을 한 줄 질문으로 (큰 타이포 + 형광펜) |
| 5–20s | 시연 | 예시 수업 화면으로 기능 동작 (기존 씬 UI 카드 재사용) |
| 20–23s | 결과 | 숫자 또는 한 줄 요약 (CountUp / 스탬프) |
| 23–25s | 엔딩 | "Classin AI로, 수업을 업그레이드." + `classin.co.kr/contact` |

## 제작 방안 (Remotion)

기존 프로젝트를 그대로 확장할 수 있습니다.

1. `src/scenes/F01Eval` ~ `F05Agent`는 이미 기능별로 분리되어 있어, 씬 단독 `Composition`으로 등록하는 것이 첫 단계입니다.
2. 훅 · 결과 · 엔딩은 공통 컴포넌트(`SeriesIntro`, `SeriesOutro`)로 만들어 5편이 공유합니다.
3. 컴포지션당 가로(1920×1080)와 세로(1080×1920) 두 규격을 함께 지원하면 SNS 배포가 쉬워집니다. 현재 UI 카드는 가로 레이아웃이라 세로 레이아웃은 별도 작업이 필요합니다.
4. 렌더는 `npm run render` 스크립트를 편별 컴포지션 ID로 확장합니다.
