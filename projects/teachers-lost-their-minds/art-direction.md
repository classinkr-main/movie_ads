# Art Direction — 선생님들은 멘탈이 나가 버렸습니다

> OpenMontage 아틀리에 모드의 "divergence engine". 장면 코드를 쓰기 전에 확정했고, 코드는 이 문서를 따라갑니다.

## Subject

수업이 끝나도 끝나지 않는 **촬영 → 편집 → 업로드 → 시청 체크**의 연쇄를, "~들은 완전히 멘탈이 나가 버렸습니다" 밈 쇼츠의
건조한 다큐 내레이션 톤으로 풀어 ClassIn 자동 녹화로 닫는 2분 11초 스토리형 쇼릴.

시각적 문제는 하나입니다 — **대사가 쉼표마다 일을 하나씩 추가한다**는 것. 그래서 쉼표 하나에 화면 동작 하나가 정확히 걸려야 하고,
일이 "쌓이는" 감각이 화면에 물리적으로 남아야 합니다.

## Design read (taste profile)

"책상 위 미니어처로 재현한 사건 보고서." 밈의 웃음은 과장된 진지함에서 나오므로, 화면은 장난감처럼 귀엽되 편집 디자인은
보도 그래픽처럼 단정해야 합니다. 귀여움과 단정함이 부딪히는 지점이 톤입니다.

| 다이얼 | 값 | 근거 |
| --- | --- | --- |
| visual_variance | 6 | 세트 7종(전시대·교실·밤 책상·구름·계단석·연구소·나무)을 오가되 블록 문법은 하나로 고정 |
| motion_intensity | 7 | 쉼표마다 낙하·스냅·팝이 하나씩. 다만 카메라는 느리게 밀고, 휩 팬은 장면 전환에만 |
| information_density | 4 | 한 프레임에 주 피사체 하나 + 꼬리표 하나. 자막과 화면 글자는 같은 말을 반복하지 않음 |

## "3D Vox 스타일" 해석

- **3D** — 실제 3D(Three.js). 둥근 모서리 블록·원기둥·구로만 조립한 토이 디오라마. 캐릭터도 블록 피규어.
- **Vox** — Vox 해설 영상의 편집 문법: 종이 질감 배경, 형광펜, 꼬리표(leader line) 주석, 도장, 큰 글자 강타, 막 구분 레일.
- 둘을 섞는 방식: 3D 물체의 좌표를 화면 좌표로 투영해서 HTML 주석을 붙입니다. 주석은 물체를 따라다니지만 글자는 항상 선명합니다.

## Type personality

- **Black Han Sans** — 큰 글자 강타 전용(멘탈이 나가 버렸습니다 / 문제였습니다 / 끝이 아니었습니다 / 그대로였죠 / 인용문 / 엔드카드).
  보도 자막 같은 무게로 밈의 "과장된 진지함"을 만듭니다.
- **Pretendard 800–900** — 자막, 꼬리표, 3D 블록에 인쇄되는 라벨.
- 모든 글자 요소는 흰 면 + 잉크 테두리 + 오른쪽 아래 하드 섀도(스티커처럼 붙은 느낌). 그라데이션·글로우 없음.

## Motion character

- **장난감 물리** — 물체는 떨어지고(낙하 8프레임), 착지하며 눌렸다가(스쿼시 0.3) 감쇠 진동으로 돌아옵니다. 등장은 오버슈트 팝(12프레임).
- **쉼표 = 동작 하나** — 구절 시작 프레임이 모든 동작의 기준점. 타이밍을 바꾸면 동작이 같이 움직입니다.
- **카메라** — 기본은 느린 푸시인 + 미세한 손떨림. 충격에는 셰이크, 장면 전환은 휩 팬(6프레임 + 블러), 막 전환은 사선 색면 와이프.
- 이징은 최소 4종을 섞어 씁니다: back(팝), expo(강타), inOutCubic(카메라), elastic(해방), 감쇠 사인(착지).

## Layout & rhythm

- 16:9 기준 하단 13%는 자막 띠, 좌상단은 "수업 끝나고 할 일" 메모, 우상단은 막 레일. 3D 주 피사체는 가운데 60%에.
- 큰 글자 강타가 나올 때는 자막을 숨깁니다(같은 문장을 두 번 보여 주지 않음).
- 컷 리듬: 1막은 3~6초 컷이 빠르게 이어지고(일이 쌓이는 호흡), 3막 나무 장면에서 처음으로 7.5초를 길게 붙잡습니다.

## Signature device — 영혼(멘탈) 가출

머리 위로 빠져나가는 작은 흰 유령. 딱 네 번만 나옵니다.

1. 오프닝 — "멘탈이 나가 버렸습니다"에서 세 명 모두 가출
2. 1막 끝 — 에너지 3%, 납작해진 선생님 위로
3. 2막 끝 — "그대로였죠"
4. 4막 — 웃는 얼굴로 **돌아와서** 선생님 안으로 들어감 (엔드카드에서는 어깨에 얹혀 있음)

구조적 장치는 하나 더: **"수업 끝나고 할 일" 메모**. 1막에서 한 줄씩 늘고, 3막에서 한 줄씩 "자동"이 되고, 4막에서 통째로 날아갑니다.
대본의 "마치 땅에서 쭉 올라온 나무처럼"은 3막 한 장면(s16)에만 씁니다.

수미상관: 첫 장면의 전시대 명판 "옛날 선생님" → 마지막 장면의 명판 "요즘 선생님". 4막에서는 촬영 장비·밤샘·링크·명단이
유리 덮개 속 전시품이 됩니다.

## Anti-references

- 이 저장소의 v1~v4 쇼릴(아이보리·라임 에디토리얼, 유리 카드 UI 목업) — 팔레트 일부만 잇고 화면 문법은 전혀 다르게.
- 보라색 그라데이션 SaaS 영상, 글래스모피즘, 네온 글로우.
- 실제 제품 화면을 흉내 낸 가짜 UI — 제품 기능을 화면으로 단정하지 않습니다. 대본이 말하는 것(버튼 하나 → 자동 촬영·업로드·시청 체크·관리)만 블록 은유로 보여 줍니다.
- 원본 밈 영상의 건물·구조물 화면을 따라 그리기 — 형식(내레이션 호흡, 문제→시도→해결 구조)만 빌립니다.
