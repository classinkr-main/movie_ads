# 개별진도 영상 | 디자인·그래픽·Higgsfield 가이드 v1.0

## 0. 전제 — 영상은 HTML 페이지의 첫 화면이다

- 최종 결과물은 `개별진도_ClassIn_v2.2_영상포함.html`이고, 영상은 페이지 맨 위 `<figure class="opening">` 안의 `#openingVideo`에 들어간다. 영상 바로 아래에 파란 그라데이션 커버(`#cover`)와 데모 모형(`.demo`)이 이어진다.
- 그래서 원칙은 하나다. **영상은 페이지의 첫 섹션처럼 보여야 하고, 영상 속 예시 화면은 페이지 데모 모형과 같은 화면이어야 한다.** 발표자가 스크롤해 데모로 내려가면 원장님이 “아까 영상에서 본 그 화면”으로 알아봐야 한다.
- 현재 들어 있는 영상은 25초 무음 초안이다(1920×1080, 30fps, 흰 배경에 파란 사람 아이콘·진행 막대·6단계 아이콘 카드, 하단 자막, 우하단 작은 ‘방향 예시’). 새 30초 영상이 이 자리를 대체한다.

## 1. 톤 결정 — 세 겹 레이어

| 레이어 | 무엇 | 톤 | 쓰는 컷 |
|---|---|---|---|
| **실사** | Higgsfield 생성 교실·책상 | 저녁 수업 다큐. 어두운 창밖 + 따뜻한 실내등, 낮은 시점, 얕은 심도 (레퍼런스 이미지 기준) | 1·2 |
| **그래픽** | 모션 텍스트, 예시 화면 모형, 실화면 프레이밍 | **HTML 페이지 톤 그대로.** 밝은 회청 배경, 잉크 텍스트, 파랑 = 지금 됨, 주황 = 개발필요 | 3·4·5·6 |
| **브랜드** | 공식 로고 | 공식 마크 원본 색·비율 유지. 엔딩 한 컷에서만 | 7 |

> **브리프 v1.0과 다른 점 (확정 필요).** 브리프는 모션 텍스트·엔딩에 오프화이트 `#f6f5f4` + 딥 에메랄드 `#084734`를 지정했다. 하지만 영상이 들어갈 페이지는 파랑 기반이고, 파랑·주황이 이미 ‘지금 됨 / 개발필요’라는 뜻을 갖고 있다. 영상에 에메랄드를 넓게 쓰면 상태 색이 하나 더 생기고 페이지와도 끊긴다. 그래서 **그래픽 전반은 페이지 토큰을 쓰고, 브랜드 색은 공식 로고가 맡게 했다.** 에메랄드를 꼭 쓰려면 엔딩의 메시지 한 줄에만 쓴다.

## 2. 디자인 토큰 (페이지 CSS에서 가져옴)

| 역할 | 토큰 | 값 | 영상 내 용도 |
|---|---|---|---|
| 배경 | `--bg` | `#f6f8fb` | 그래픽 컷 바탕, 엔딩 바탕 (페이지 배경과 이어짐) |
| 카드 | `--card` | `#ffffff` | 모형 카드, 실화면 프레임 |
| 본문 | `--ink` | `#1b2430` | 제목·자막·모형 상단 바 |
| 보조 | `--sub` | `#5b6675` | 보조 문구, 각주 |
| 선 | `--line` | `#e3e7ee` | 헤어라인, 카드 테두리 |
| 지금 됨 | `--ci` / `--ci-bg` | `#1f6feb` / `#e8f0fe` | 실화면 칩, 진행 막대, 커서 클릭, 강조 |
| 개발필요 | `--ai` / `--ai-bg` | `#e8590c` / `#fff1e6` | ‘방향 예시’ 표시, 예시 카드 좌측 선, 학생 강조 깃발 |
| 예시 스탬프 | `.demo-bar .stamp` | `#ffe066` / `#5c3c00` | 모형 상단 바의 ‘예시 화면 · 가짜 데이터’ |
| 브랜드 | 공식 마크 | `#00a975`~`#00b67e` 그라데이션 | 로고에만. 글자·도형에 쓰지 않음 |

- **영상에서는 파랑·주황 두 가지 상태색만 쓴다.** 페이지의 보라(데이터 연결 검토)는 영상 화면 전체가 이미 ‘개발필요’로 표시되므로 주황 체계로 통일한다. 초록(팩트)·노랑(구상)·회색(범위 밖)은 쓰지 않는다.
- 그림자: 카드 `0 8px 32px rgba(27,36,48,.08)`. 모서리: 카드 16px, 칩 999px, 모형 프레임 16px(페이지 `.demo`와 같음).

글꼴은 **Pretendard**(레포 `public/fonts`, 페이지 폰트 스택에도 포함).

| 용도 | 크기 / 굵기 | 색 | 위치 |
|---|---|---|---|
| 자막 | 44px / SemiBold, 행간 1.35, 한 줄 최대 24자 | 그래픽 컷: `--ink` · 실사 컷: 흰색 | 하단 중앙, 바닥에서 96px |
| 메인 카피 (컷 3) | 96px / Bold, 자간 -2% | `--ink`, 핵심어만 `--ci` | 화면 중앙 |
| 엔딩 제목 | 88px / ExtraBold | `--ink` | 중앙 위 |
| 엔딩 메시지 | 40px / SemiBold | `--ink` (에메랄드 선택 시 이 줄만) | 제목 아래 |
| 표시 칩 | 26px / Bold, 패딩 8×18 | 1장 상태색 | 우측 상단(예시)·좌측 상단(실화면), 가장자리에서 64px |
| 모형 UI 본문 | 26~30px | 페이지 모형 색 그대로 | 페이지 모형의 약 1.9배 확대 |

- 안전 영역: 좌우 96px, 상하 64px. 모형 프레임은 1600×860 안에 넣는다.

## 4. 그래픽 스타일

**4-1. 예시 화면 = 페이지 데모 모형의 확대판 (컷 4·6)**
- 페이지 `.demo` 구조를 그대로 그린다. 상단 잉크 바(`중2 수학 개별진도반 A (가상)` + 노란 스탬프 `예시 화면 · 가짜 데이터`) → 탭 줄 → 본문 카드.
- 카드는 페이지처럼 **좌측 6px 주황 선**(`.box.ai`)과 `[개발필요]` 알약 칩을 단다.
- 데이터도 페이지 값 그대로 쓴다.
  - 원장 대시보드: 어제 데일리 테스트 반 평균 **78점**, 오늘 먼저 볼 학생 **C · E**, 학생 A~F 표(오늘 진도·위치·어제 테스트 80/90/55/85/62/95점, 표시 깃발 ‘금요일 합반 후보 / 숙제 미완 3회 / 최근 하락 / 상위반 구상 후보’)
  - 학생 E 한 화면: 진도 경로 `방정식 복습 → 일차방정식 활용 → 활용 재도전 → 연립방정식 도입`, 점수 추이 70·74·68·66·62
  - 학부모 리포트(학생 E): 오늘 한 일 “오늘은 일차방정식 활용을 다뤘습니다.” / 막힌 점 “식을 세운 뒤 부호를 정리하는 문항에서 막혔습니다.” / 다음에 할 일 “내일은 같은 유형 다섯 문항과 짧은 테스트를 합니다.” 상단 라벨 ‘AI 생성 예시’.
- 컷 4의 ‘AI 진도 설계’ 화면은 페이지에 아직 없는 화면이다. 같은 모형 프레임 안에 새 탭 ‘⓪ AI 진도 설계’를 만들고, 페이지의 `.path` 칩 스타일(완료 = 연초록, 현재 = 파랑 테두리, 다음 = 흰색)로 학생 A~F 4주 경로를 레인으로 그린다. 영상을 확정하면 **같은 화면을 페이지 데모에도 탭으로 추가**해 연결을 맞춘다.

**4-2. 아이콘·인포그래픽 (컷 2·3)**
- 기존 초안 영상의 언어를 이어 쓴다. 파랑 원형 사람 아이콘, 얇은 진행 막대, 2px 선 아이콘(깃발·체크·격자·말풍선·상담·문서).
- 컷 2의 떠오르는 단어는 페이지의 **개별진도 6단계** 그대로 쓴다. `진도 배정 · 데일리 테스트 · 숙제 · 질문 · 상담 · 학부모 보고`. 6개 아이콘 칩이 실사 위로 하나씩 떨어져 쌓인다.
- 컷 3에서는 쌓인 6개 칩이 화면 중앙으로 모여 한 줄로 정렬된 뒤, 문장 “AI로 설계하고, 한 화면에서 관리한다면요?”로 바뀐다. 칩이 정렬되는 동작이 곧 ‘한 화면’의 은유다.
- 선택: 컷 1 실사에서 학생 머리 위로 길이가 다른 파란 진행 막대 6개를 얹어 ‘여섯 갈래 진도’를 보여 준다. 카메라가 거의 고정이라 위치를 맞추기 쉽다.

**4-3. 실화면 프레이밍 (컷 5)**
- 데모 녹화는 브라우저·OS 바를 잘라 내고 흰 카드(모서리 16px, 그림자) 안에 넣는다. 바탕은 `--bg`.
- 좌측 상단 칩: `지금 됨 · ClassIn 실제 화면`(파랑). 채팅 질문이 도착할 때 해당 패널로 1.4배 확대한다.
- 실화면 위에는 커서·하이라이트 외 그래픽을 얹지 않는다. 예시 화면 요소는 절대 섞지 않는다.

**4-4. 모션 규칙**
- 기본 이징: ease-out cubic 300~500ms. 칩·카드 등장은 약한 스프링(튀지 않게).
- 카메라: 실사는 느린 push-in·pull-back만. 그래픽 컷은 3% 이내 줌 드리프트.
- 클릭 연출: 파란 원형 리플 1회 + 화살표 커서. 자동 연결처럼 보이지 않도록 클릭 → 화면 전환을 한 박자 띄운다.
- 전환:
  - 실사 → 그래픽: 흰 디졸브 8프레임
  - **실화면 ↔ 예시 화면: 화면을 `--bg`로 6프레임 비운 뒤 칩을 바꿔 단다**(섞임 방지)
  - 그래픽끼리: 좌→우 슬라이드 12프레임
- 금지: 글리치, 네온, 3D 회전, 과한 파티클, 다크 모드 화면.

**4-5. 표시(라벨) 규칙**
- 예시 화면 전 구간 우측 상단: `방향 예시 · 개발필요 · 가상 데이터`(주황 칩, 26px). 모형 안의 노란 스탬프와 함께 표시한다.
- 실화면 구간 좌측 상단: `지금 됨 · ClassIn 실제 화면`(파랑 칩).
- 실사·모션 텍스트 컷에는 칩을 달지 않는다.
- 엔딩 각주: “AI 진도 설계·원장 대시보드·학부모 리포트는 개발이 필요한 방향 예시이며, 화면 속 학생과 점수는 가상 데이터입니다.”

## 6. Higgsfield 적용 요소

**6-1. 쓰는 곳 / 안 쓰는 곳**

| 쓴다 | 안 쓴다 |
|---|---|
| 컷 1 수업 중 교실(뒷모습·손) | 제품 UI, 대시보드, 리포트 등 모든 화면 → Remotion 모형 또는 실화면 |
| 컷 2 수업 후 선생님 책상 | 글자, 숫자, 로고, 자막 → 편집기에서 합성 |
| | 사람 얼굴, 실존 학원·인물 |
| | 내레이션·BGM → 팀원 녹음 + 사용 승인 BGM (브리프 유지) |

UI를 생성하지 않는 이유: 생성된 화면은 실제 제품처럼 보여 ‘제공 기능’ 오해를 만들고, 글자가 깨지며, 페이지 데모와 일치시킬 수 없다.

**6-2. 룩 바이블 (레퍼런스 `20261122_opening_ref.png` 기준)**
- 시간대: **저녁 수업**. 창밖은 어두운 남색 밤, 실내는 형광등 + 따뜻한 반사광. 브리프의 ‘late-afternoon’ 프롬프트는 레퍼런스와 맞지 않아 저녁으로 바꿨다(개별진도 학원은 저녁 수업이 주력).
- 공간: 작은 한국 수학학원. 연한 목재 상판 + 회색 금속 다리 책상·의자, 화이트보드, 책꽂이.
- 카메라: 책상 높이의 낮은 시점, 35~50mm 느낌, 얕은 심도, 전경 선명·배경 흐림.
- 색: 채도 낮춤, 따뜻한 나무색과 차가운 창밖의 대비. 필름 그레인은 아주 약하게.
- 반복 소품: **모눈 노트, 연필, 파란 띠가 있는 접힌 크림색 질문 쪽지.** 쪽지의 파랑이 페이지의 ‘지금 됨’ 파랑(`#1f6feb`)과 이어지는 시각 고리다. 컷 1·2에 모두 등장시키고, 컷 5의 채팅 질문으로 이어진다.

## 7. HTML 삽입 사양

- **교체 위치**: `<video id="openingVideo" src="data:video/mp4;base64,…">`의 `src`. `controls playsinline preload="metadata"`는 유지하고, 내레이션이 있으므로 `autoplay`는 넣지 않는다(발표자가 직접 재생).
- **poster**: 엔딩 프레임(컷 7)을 JPG로 뽑아 `poster`에 넣는다. 재생 전에도 페이지 히어로로 보인다.
- **인코딩**: 1920×1080, 30fps, H.264 High, yuv420p, AAC 128kbps, `-movflags +faststart`. 파일 크기는 **8MB 이하**를 목표로 한다. base64로 넣으면 약 1.33배가 되어 HTML이 11MB 안팎이 된다. 단일 파일 공유가 중요하면 이대로 넣고, 무거우면 `opening.mp4`를 HTML 옆에 두고 상대 경로로 바꾼다.
- **자막 목록 갱신**: 페이지의 `.opening-captions` 목록을 30초 내레이션 7줄로 바꾸고, 아래 표시 문구를 `영상 10~14초, 19~24.5초 방향 예시`로 고친다.
- **선택**: SRT를 VTT로 바꿔 `<track kind="captions" srclang="ko" default>`로 넣는다. 화면에 자막이 이미 들어가 있으므로 기본은 끈다.
