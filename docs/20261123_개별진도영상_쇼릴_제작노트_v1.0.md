## 3. v3 디자인

- **콘셉트:** 문제는 선생님의 공책으로(연필 자리표, 플래너 위 포스트잇 36장, 빨간 펜 동그라미), 해결은 ClassIn 앱 화면으로 보여 줍니다. S3에서 포스트잇이 앱 창 하나로 빨려 들어가며 넘어갑니다.
- **앱 화면:** 데스크톱 앱 홈(창 틀·검색·검정 알약·좌측 사이드바·코스 카드·우측 패널), 수업 다시보기의 AI 강의 분석 패널(탭·AI 점수·지표 카드)을 가상 데이터로 다시 그렸습니다. 캡처는 넣지 않아 실제 계정명·고객 데이터가 들어가지 않습니다.
- **글꼴:** 제목 고운바탕 Bold(따뜻한 명조), 메모 나눔손글씨 펜, 앱 안 글자 Pretendard.
- **색:** 종이 색이 장면마다 조금씩 바뀝니다(저녁 공책 → 바쁜 책상 → 새 페이지 → 모눈종이 → 아침 → 낮). 학생 여섯은 색연필 여섯 색으로 평면도부터 엔딩까지 이어집니다.

## 4. 제작 흐름과 도구

1. **지식베이스:** 설명회 페이지 v2.2의 기능 상태표와 가상 반 데이터, Notion 「AI 강의 분석 기능 소개」의 관리자 콘솔·한국어 리포트 화면, 공식 사이트의 앱 화면을 참고 자료로 썼습니다.
2. **콘티 → 코드 시안:** Remotion(React 기반 영상 엔진)으로 컷마다 정지 프레임을 뽑아 검토하고 고쳤습니다. 피드백 세 번을 모두 코드 수정으로 반영했습니다.
3. **음악·효과음:** 120 BPM으로 컷 시점(4·8·10·14·18·24초)에 맞춘 오리지널 트랙을 Python(numpy·scipy)으로 합성했습니다. 측정값은 통합 −15.0 LUFS, 트루피크 −1.3 dBTP입니다. 발표장 스피커에서 10초·24초 저음 크기는 한 번 들어 보고 조정합니다.
4. **생성형 이미지·영상:** 쓰지 않았습니다(생성 크레딧 0). 이 작업 세션에서는 Higgsfield 생성 기능을 쓸 수 없었고, 기존 레퍼런스 이미지는 쓰지 않기로 했습니다.

## 5. 표시·준수 사항

- S4(AI 진도 설계)·S6(원장 화면·학부모 리포트)은 전 구간 우측 상단에 도장 `EXAMPLE · 방향 예시 · 개발필요 · 가상 데이터`를 고정했습니다.
- S5(수업방 채팅 질문·녹화·AI 강의 분석)는 `AVAILABLE NOW · 지금 됨 · ClassIn 화면 재구성 · 가상 데이터`로 표시했습니다. 채팅 장면과 AI 강의 분석 장면은 화면 전환으로 분리했습니다.
- AI 강의 분석 지표 이름은 실제 앱 화면(지식 설명 품질 · 사고 수준 및 방법 정리 · 학생 학습 품질 · 수업 구조 및 효율)을 따랐고, 점수는 예시 값입니다.
- **확인 필요:** Notion 「AI 강의 분석 기능 소개」(2026.04)에는 "현재 중국어로만 제공"이라고 되어 있습니다. 설명회 페이지 v2.2와 브리프는 '지금 됨'이라 영상도 그렇게 표시했으니, 발표 전에 최신 제공 언어를 확인합니다.
- 학부모 리포트는 "초안" 도장까지만 보여 주고 발송 장면은 없습니다. 엔딩 하단에 예시·가상 데이터 각주를 고정했습니다.
- 실명·학원명·가격·연락처·녹취 원문은 없습니다. 학생은 A~F 가상 식별자입니다.

## 6. 복기 초안 (최종 확인 후 다듬기)

- **얻은 것:** 기능 상태표를 먼저 정리해 두니 "보여 줄 수 있는 것 / 예시로만 보여 줄 것"이 화면 설계 단계에서 갈렸습니다. 코드 기반이라 피드백 세 번(톤·장식·글꼴·앱 화면)을 매번 전체 재렌더로 빠르게 반영했습니다.
- **겪은 문제:** 디지털 톤(발광·유리 카드)이 "AI가 만든 것 같다"는 인상을 줬고, 원장님 대상 영상에는 손글씨·종이 같은 학습 현장의 질감이 더 잘 맞았습니다. 실제 앱 화면을 참고하자 제품이 무엇인지가 바로 읽혔습니다.
- **업무 시사점:** 설명회 페이지의 가상 데이터와 같은 값을 영상에 쓰면 오프닝 → 데모가 하나의 이야기로 이어집니다. 문제(아날로그) → 해결(앱)의 대비는 다른 기능 소개 영상에도 쓸 수 있는 틀입니다.
- **다음 단계:** 데모 계정 실화면 녹화로 S5 교체 여부 결정, AI 강의 분석 제공 언어 확인, 발표장 스피커 점검, 9:16 세로 버전(SNS용) 파생.
