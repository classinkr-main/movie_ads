## 2. 디자인 방향 (Wayne 피드백 반영)

- **뺀 것:** 레퍼런스 사진, 라벨 왼쪽의 점·색 사각형, 카드 왼쪽 색 띠, 큰 둥근 모서리, 과한 발광.
- **넣은 것:** 직접 그린 라인 아이콘 29종(획이 그려지며 등장), 교실 평면도·치수선·방위표, 학생별 지하철 노선, 6×6 업무 매트릭스, 코너 브래킷·크롭 마크·타임코드·초안 스탬프.
- **색:** "하루의 빛"으로 장면마다 조금씩 바뀝니다. 밤(남색) → 열기(주황빛 어둠) → 암전 → 새벽(청록) → 블루아워 → 아침(밝은 세이지) → 낮(웜화이트). 마지막 프레임이 밝아 HTML 페이지와 자연스럽게 이어집니다.
- **반복 모티프:** 학생 여섯 = 노선 여섯. 평면도에서 갈라지고(S1), AI가 4주 노선으로 설계하고(S4), 대시보드 행과 학생 E의 경로로 이어지고(S6), 엔딩에서 ClassIn 마크로 모입니다(S7).

## 3. 제작 흐름과 도구

1. **지식베이스:** 설명회 페이지 v2.2의 기능 상태표(지금 됨 / 개발필요)와 가상 반 데이터(학생 A~F, 점수, 진도)를 그대로 가져와 화면 데이터로 썼습니다.
2. **콘티 → 코드 시안:** Remotion(React 기반 영상 엔진)으로 컷마다 정지 프레임을 먼저 뽑아 검토하고 고쳤습니다. 카피·데이터·색·타이밍을 코드에서 바꾸고 다시 렌더할 수 있습니다.
3. **음악·효과음:** 120 BPM으로 컷 시점(4·8·10·14·18·24초)에 맞춘 오리지널 트랙을 Python(numpy·scipy)으로 합성했습니다. 외부 음원을 쓰지 않아 라이선스 문제가 없습니다.
4. **생성형 이미지·영상:** 이번 버전에서는 쓰지 않았습니다. 기존 레퍼런스 이미지를 쓰지 말라는 방향에 따라 전 장면을 모션그래픽으로 그렸고, 이 작업 세션에서는 Higgsfield 생성 도구를 쓸 수 없었습니다. 실사 컷이 필요하면 S1·S2 배경에 추가할 수 있습니다.
5. **비용:** 생성 크레딧 0. 렌더는 클라우드 세션에서 약 3분.

## 4. 표시·준수 사항

- S4(AI 진도 설계)·S6(대시보드·학생별 한 화면·학부모 리포트)은 전 구간 우측 상단에 `EXAMPLE | 방향 예시 · 개발필요 · 가상 데이터`를 고정했습니다.
- S5(수업방 채팅 질문·녹화·AI 강의분석)는 `LIVE | 지금 됨 · ClassIn 기능`으로 표시했습니다. 채팅 장면과 AI 강의분석 장면은 화면 전환으로 분리해, 채팅 질문이 녹화와 자동 연결되는 인상을 피했습니다.
- S5는 기능 설명 그래픽입니다. 브리프 원칙대로 실화면을 쓰려면 한국판 데모 계정 녹화를 `S5Record.tsx`의 수업방·분석 패널 자리에 넣으면 됩니다(구도·타이밍 유지).
- 학부모 리포트는 "초안" 스탬프까지만 보여 주고 발송 장면은 없습니다. 엔딩 하단에 예시·가상 데이터 각주를 고정했습니다.
- 실명·학원명·가격·연락처·녹취 원문은 없습니다. 학생은 A~F 가상 식별자입니다.

## 5. 복기 초안 (최종 확인 후 다듬기)

- **얻은 것:** 기능 상태표를 먼저 정리해 두니 "보여 줄 수 있는 것 / 예시로만 보여 줄 것"이 화면 설계 단계에서 자동으로 갈렸습니다. 코드 기반 모션그래픽은 문구·데이터 수정이 즉시 반영되어 반복이 빨랐습니다.
- **겪은 문제:** 첫 시안이 다크 그린 발광·둥근 카드 위주라 "AI가 만든 것 같은" 인상이 났습니다. 장식용 점·색 띠·둥근 모서리를 빼고 아이콘·선·타이포로 강조하는 방향으로 바꿨습니다.
- **업무 시사점:** 설명회 페이지의 가상 데이터와 같은 값을 영상에 쓰면, 영상(오프닝) → 데모(본편)가 하나의 이야기로 이어집니다.
