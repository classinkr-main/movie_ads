# 개별진도 영상 | 30초 기획 v2.0

## 1. 한 줄 요약

**손이 많이 가는 개별진도를, AI로 설계하고 ClassIn 한 화면에서 관리하는 그림을 보여 주고 — 시작은 지금 되는 수업방·녹화로 반 하나부터라고 맺는 30초 오프닝.**

- 대상: 개별진도반을 운영하거나 도입을 검토하는 학원 원장
- 문제: 학생마다 진도가 달라 설계·채점·질문·상담·학부모 보고에 사람 손이 많이 든다. 그래서 개별진도는 품질을 지키기도, 수익을 내기도 어렵다.
- 메시지: **AI가 진도를 설계하고, 수업 기록이 대시보드로 모이면, 원장님은 적은 손으로 수업 퀄리티와 학부모 만족을 챙길 수 있다.**
- 사양: 1920×1080 · 30fps · **30초(900프레임)** · H.264 MP4 + AAC · 한국어 내레이션·자막 · 가사 없는 BGM. 설명회 오프닝과 본사 과제에 같은 마스터를 쓴다.
- 마감: 본사 과제 2026-11-28(토) 00:59 KST. 팀 내부 납품 시각·설명회 일시 **[확인 필요]**.

## 10. 본사 과제 제작설명 초안 (복기는 완성 후 작성)

- **주제 선정**: 한국 학원 원장 대상 설명회의 오프닝. 개별진도는 학생마다 설계·관리 손이 많이 들어 품질과 수익을 함께 지키기 어렵다는 현장 의견에서 출발해, AI 설계와 대시보드 관리라는 방향을 30초로 보여 준다.
- **제작 흐름**: 설명회 페이지의 기능 상태표(지금 됨 / 개발필요)를 지식베이스로 써서 실화면과 예시 화면을 구분했다 → 콘티를 정지 이미지와 코드 시안으로 먼저 재생해 문장을 다듬었다 → 장면 성격에 따라 도구를 나눴다.
- **모델·도구 분담**: 실제 교실 장면은 Higgsfield(이미지 → 영상화, 컷당 시도 상한), 개발 전 화면과 텍스트는 Remotion 코드(0 크레딧), 지금 되는 기능은 데모 계정 실화면 녹화.
