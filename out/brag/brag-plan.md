# Brag Plan: Classin AI (v5 · 9:16 · 20s · cinematic)

## 이게 뭔가
수업 플랫폼 Classin의 AI가 수업이 끝나면 강의를 분석하고, 숙제를 채점하고, 수업 중에는 교사의 말을 학생 언어로 통역한다.

## 각도
"선생님은 가르치기만 하세요." 수업 뒤에 따라오는 일(평가·채점·통역)을 AI가 이미 끝내 놓은 상태로 보여 준다.
v4(30초)가 기능 5개를 설명했다면, v5는 **3개만, 일하는 장면으로, 영화 예고편의 문법으로** 보여 준다.

## 톤 — `cinematic`
트레일러 스케일, 큰 타입, 극적인 전환. 조명이 이야기를 끌고 간다:
**어둠(콜드 오픈) → 화이트 플래시(타이틀) → 어두운 스튜디오에서 빛을 받는 카드(하이라이트) → 플래시 → 밝은 엔딩(CTA)**.

## 타입 시스템
| 역할 | 폰트 | 쓰임 |
|---|---|---|
| 국문 헤드라인 | Noto Serif KR — Light ↔ Black 대비 | 하이패션 디돈 톤의 명조(4종 비교에서 B 선택, `out/brag/typeset/`). 블러 인 + 자간이 조여지며 등장 |
| 영문 액센트 · 큰 숫자 | Bodoni Moda Italic | `Lesson Evaluation`, `88`, `90`, `— just teach.` |
| 시간 | Bodoni Moda (다이얼 숫자 · 디지털 창) | 크로노그래프 다이얼의 5분 숫자와 `60:00` 창 |
| HUD · 데이터 | JetBrains Mono | 영상 타임코드 `00:00:05:12`, `SC.01 / 03`, `REC`, 카드 점수 |
| UI 본문 | Pretendard | 카드 안 텍스트(기존 v4와 동일) |
| `AI` 로고타입 | 직접 그린 SVG(`src/brag/Brand.tsx`) | 워드마크와 같은 획 두께(33)·캡 높이·사선 컷(≈20°). A는 n의 아치, I는 i의 사선 컷. 색은 새 마크의 그라데이션 |

## 아이콘
`src/brag/Icons.tsx` — 64 그리드 라인 아이콘, 둥근 끝, 아이콘마다 포인트 획 하나(연두). 획이 그려지듯 나타난다.
- **분석**: 렌즈 속 파형 · **채점**: 답안지 밖으로 뻗는 체크 · **통역**: '가' 말풍선 → 'A' 말풍선
- 타이틀 카드의 세 기능 열(아이콘 · 국문 · 영문)과 각 하이라이트의 영문 라벨 앞에 쓴다.

## 연출 장치
- **카메라**: 장면마다 가까이서 시작해 풀백(1.16→1.0), 이후 느린 푸시인 + 미세한 핸드헬드 흔들림.
- **3D 카드**: 깊이(-520px)에서 회전하며 들어와 초점이 맞고(블러 16→0), 안착하면 유리 광택이 한 번 지나간다. 연두 림 라이트.
- **크로노그래프 다이얼**(`src/brag/Dial.tsx`): 콜드 오픈의 1시간을 아날로그로. 기요셰 문양, 60개 분 눈금과 5분마다 보도니 숫자, 바늘 뒤 빛 꼬리, 연두 게이지 아크. 바늘이 지난 눈금이 켜지고 12시에서 살짝 흔들리다 멈추며 종료 펄스. 분석 카드의 88 링도 같은 눈금·캡 언어.
- **랙 포커스**: 콜드 오픈에서 알림이 도착하면 뒤의 타이틀·다이얼이 흐려지고 어두워진다.
- **스케일 대비**: 카드 뒤에 화면을 벗어나는 거대 이탤릭 숫자(88 · 90)와 언어 이름(English · 中文 …)이 초점 밖에서 들어온다.
- **필름 룩**: 볼류메트릭 빛줄기, 보케와 먼지, 비네트, 필름 그레인, 콜드 오픈의 레터박스.
- **전환**: 화이트 플래시(+아나모픽 빛줄기) · 줌 스루 · 휩 팬(모션 블러) · 화이트 플래시. 모두 겹침 없이(이중 노출 없음).

## 구도
- 하이라이트: 상단 HUD → 좌측 정렬 타이틀(상단 1/3) → 3D 카드(하단 2/3, 프레임 폭 가득). 배경 숫자는 우측으로 잘려 나간다.
- 콜드 오픈 · 타이틀 · 엔딩: 중앙 대칭.
- 릴스·쇼츠 UI 가림 영역(상단 ~200px, 하단 ~380px)을 피해 핵심 정보는 y 200–1540.

## 스토리보드 (30fps · 600f · 120 BPM)

장면 도착은 3 · 5 · 9 · 13 · 17s, 모두 다운비트.

## 사운드
`scripts/brag-audio.py`가 `src/brag/cues.json`을 읽어 합성한다(numpy + ffmpeg loudnorm, -14 LUFS).
- 0–3s: D 드론 + 크로노 시작 푸셔 → 바늘이 5분 눈금을 지날 때마다 기계식 이스케이프먼트 틱(틱·톡 교대, 다이얼과 같은 이징) + 바늘 아래 공기 스윕 → 정지 푸셔와 낮은 케이스 톡 → 튜블러 벨 차임 → 라이저.
- 숫자 롤(88 · 90)도 같은 기계식 틱이 점점 느려지는 소리, 분석 스캔은 부드러운 공기 스윕.
- 3.0s 드롭: 브람(필터가 닫히는 옥타브 톱니) + 타이코 붐 + 크래시.
- 5–17s: D단조 i–VI–III–VII. 16분 펄스 오스티나토 · 스트링 패드 · 킥/타이코, 장면마다 강도 증가. 휩 착지마다 타이코.
- 16.8s 플래시 정점에서 끊기고 17s에 F장조로 해결 → 벨 아르페지오, CTA 탭에 벨.
- 효과음은 같은 조의 음높이(스탬프 · 블립 · 칩 벨은 D단조 화음 음)로 맞추고 음악 밑에 깐다.

## 공개용 데이터 점검
- 수업·교사·학생 이름은 모두 가상(중2 국어 A반 · 이서윤 선생님 · 김지민 · Alex · Lin · Yui · Thu).
- 점수(88 · 90 · 반 평균 82)와 발문 위치는 **예시 화면**이며 모든 카드에 라벨이 붙어 있다.
- AI 강의 평가는 Notion 기준 현재 중국어 수업·실시간 수업에만 제공 — 영상은 언어를 단정하지 않는다.
- 지원 언어(English · 中文 · 日本語 · Tiếng Việt)는 v4와 같은 예시 — 실제 지원 범위에 맞춰 조정 필요.
- 비밀 정보·내부 URL·실제 개인정보 없음. CTA URL은 공개 도메인.
